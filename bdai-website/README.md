# BDAI website

Static, single-page site for BDAI (formerly BDBA) in a tech-blue theme. It covers:

- **Experimentium**, the studio, and its two products: **Mathopea** (visual mathematics) and **Electron** (new science experiment startup).
- **Electron lab**: interactive model curves for experiments taken from the maths papers (cooling tea, bacteria culture, RL circuit, town population).
- **Showcase**: an animated slide deck (Mathopea, Electron, team results, maths papers).
- **Team**: employee marks for 2026–27, sortable and filterable.
- **Papers**: Senior Secondary Mathematics Papers I–III (page images in `papers/`) and the new 80-mark Differential Equations Exercise Paper with worked solutions.

Open `index.html` in a browser. No build step is needed.
