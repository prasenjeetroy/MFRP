          // Architecture
          
    How the Databell platform fits together.
    
          
    Five layers, from the screens people use down to the infrastructure that runs them. Select a component to see what it does, or trace a request through the stack.

    Design decisions
    
        
    
          
    ADR-01
    Calculation stays separate from presentation
    Every rule lives in a pure function that can be tested without the interface. Screens only display what the function returns.
    
          
    ADR-02
    Validate at the edge of every function
    Empty titles, text where numbers belong, booleans, infinities and out-of-range counts are rejected before any work starts.
    
          
    ADR-03
    Keep the raw data
    Summaries are always traceable back to the readings and events that produced them. An average is never treated as proof.
    
          
    ADR-04
    Ship a small first release
    Start in memory, prove the behaviour with tests, then discuss persistence, duplicates and access control before growing.

          // FAQ
          
          Questions, answered.
          
          
          Can't find what you need? Our team replies within one business day.
          
          Ask us directly 
        
          
        
          
          
          
            Can I work with just one Databell extension?
            
          Yes. DatabellSoftwareLabs, TechEnhance and TechKnowledge each take engagements on their own. Many clients start with one and add the others later.
          
          
          
          
          
            How quickly can a Labs squad start?
            
          Usually within two weeks of signing. Discovery starts in week one and you see working software by the end of the first sprint.
          
          
          
          
          
            Will modernisation take our systems offline?
            
          No. TechEnhance migrates piece by piece behind feature flags and traffic shadowing, so the old system keeps serving until the new one is proven.
          
          
          
          
          
            Are TechKnowledge certificates recognised?
            
          Each certificate has a public verification link, and the cloud tracks map to the official AWS, Azure and GCP exam objectives.
          
          
          
          
          
            Can I download the original presentations?
            
          Yes. Each deck in the Presentations viewer has a download button for the original PowerPoint file. The web versions are rebuilt from the same content, so you can present them in any browser.
          
          
          
          
          
            Do the Python, SQL and C++ samples in the Code Lab really run?
            
          HTML, CSS and JavaScript run for real in a sandboxed frame. Browsers can't run Python, SQL or C++, so the Code Lab works out each program's output with an equivalent JavaScript function and marks the result as simulated. SQL queries run against small sample tables, which the Code Lab shows next to the results.
          
          
          
          
          
            Who owns the code you write?
            
          You do. All source code, infrastructure definitions and documentation are transferred to you, with no lock-in.
